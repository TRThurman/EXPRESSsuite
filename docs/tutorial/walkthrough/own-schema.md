## On your own schema

Open the folder that holds your `.exp` files (the folder, not one file, so
that the schemas a schema interfaces are found).

| To | Do |
|---|---|
| read the description of a name | hover it, or right-click → **Show Description** |
| write a description block | right-click the declaration → **Describe Declaration** |
| see what the checks report | open the **Problems** panel |
| see the EXPRESS-G diagram | right-click → **Show EXPRESS-G Diagram** |
