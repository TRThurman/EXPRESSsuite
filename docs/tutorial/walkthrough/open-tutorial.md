## The tutorial and its demo

**EXPRESSsuite: Open Tutorial** opens a window of its own with

- a copy of two small demo schemas (all names in them are made up), and
- the tutorial text beside them.

The first time, VS Code may open the new folder in Restricted Mode, where
EXPRESSsuite does not run. If so, click **Restricted Mode** in the status bar of the
new window and choose **Trust**; the tutorial then opens.

The tutorial takes you through the description check in the Problems panel,
the **Describe Declaration** command and the publication checks. You edit the
copy; your own files are not touched. Run the command again to continue, or
to start over with a fresh copy.
